# I Built a Brain Scanner for UI Design

## cuts

- chair — main talking position, relaxed
- close — up-close face, emphasis moments
- screen — screen recording / terminal
- broll — generated visuals, brain heatmaps, mockups
- black — end card

## the script

[chair]
So Meta recently released v2 of their fMRI scan prediction neural network TRIBE.
[close]
fMRIs are these scans that show where in the brain blood is moving around and so the TRIBEv2 neural network predicts how 20,000 different points on your cortex will be activated by visual, audio, and text stimuli.
[screen: terminal running experiments, brain images generating]
so obviously i immediately started feeding it descriptions of user interfaces. like what does a clean google-style search page do to your brain versus a page covered in popups, auto-playing video, flashing banners, cookie consent walls — the whole nightmare.
[broll: clean UI mockup | cluttered UI mockup side by side]
and the answer is: completely different brains. the cluttered version JACKS your frontal cortex. your brain is working overtime just to find the content.
[broll: paired brain heatmaps, then diff brain red/blue]
it's not engagement. it's struggle.
[close]
but here's where it gets actually disturbing.
[chair]
i tested dark checkout patterns. you know — the pre-checked insurance, the "you're about to miss out" copy, hidden fees that show up at the last step. and i compared them to an honest checkout. three items, clear price, one button, pay now.
[broll: honest checkout mockup | dark checkout mockup side by side]
the dark version FLIPS your brain's reward signal positive.
[close]
your orbital frontal cortex — the part that goes "ooh nice" — it lights up MORE for the manipulative version.
[broll: rotating brain diff GIF, red hotspots on reward regions]
your brain is literally rewarding you for being tricked. that's the mechanism. that's WHY dark patterns work even when you KNOW they're dark patterns.
[chair]
and then i tested flow. a clean code editor — fullscreen, instant autocomplete, no distractions — versus one that hits you with a save dialog every two minutes and has a notification badge in the corner.
[broll: flow editor mockup | interrupted editor mockup]
the interrupted version doubles your cognitive load. but here's the trap —
[close]
engagement metrics go UP too. so if you're a company optimizing for engagement, you converge on the thing that makes brains struggle. the metric lies.
[chair]
so i did something about it. i derived eight brain-based signals from the data.
[broll: HIX dashboard heatmap, labels appearing]
cognitive load. frustration. flow. trust. reward. confusion. engagement. spatial clarity. i'm calling them HIX signals — human interface experience.
[broll: closed-loop diagram — generator → TRIBE v2 → HIX → gradient back]
the idea is these become the reward function for autonomous UI design. not "did users click" but "did users' brains thrive." and you don't need real users in the loop — the brain model IS the virtual user.
[close]
but you need trust as a HARD constraint. because if you optimize purely for reward, you literally converge on dark patterns. the brain rewards manipulation. so you have to build the ethics into the math.
[chair]
all the code is open source. every experiment, every visualization, the whole pipeline.
[close]
because i think being able to see what design does to brains should be a public capability. not a competitive moat.
[chair, direct to camera, let it breathe]
bad UX isn't just annoying. it is measurably violent to cognition.
[hold 1 beat]
and now we can see it.
[black: github link + handle]
